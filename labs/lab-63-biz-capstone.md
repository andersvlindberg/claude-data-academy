# Lab 63: Business capstone: a data-driven growth plan for Nordvik

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Business / MarTech | L3 | 8–10 h | Slides, Looker Studio, CRM | Free |

**Goal:** Present a 12-month growth plan grounded in customer and channel data.

## How this lab works
1. **Hub:** open this step in your study hub and take the lecture (*Lecture*), or skip it if you know the theory.
2. **Claude Code:** the lecture ends with a practice project. Claude sets it up for you (a fictional scenario and generated data) and you build it in a real tool.
3. **GitHub:** commit as you go and merge it into your fork. Then tick it off in the hub.

```bash
cd claude-data-academy        # your fork
git checkout -b lab-63
mkdir -p my-work/lab-63-biz-capstone && cd my-work/lab-63-biz-capstone
claude
```
Type `LAB 63`. This is a brief lab: the coach turns the milestones below into steps for your level, and you write the code.

## Milestones
1. Journey map, metric tree and segments
2. Channel and campaign analysis
3. Automation and CRM plan with privacy built in
4. A board-style 10-slide presentation

## Done when
- [ ] Every recommendation has a metric
- [ ] Privacy addressed

## Save it to your portfolio
```bash
git add .
git commit -m "lab 63: <what you built>"
git push -u origin lab-63
```
Open a pull request in your fork, read your own diff like a reviewer, merge it, and mark the lab *Done* in your hub. Add a short `README.md` in the lab folder: what you built, how to run it, what you learned.
