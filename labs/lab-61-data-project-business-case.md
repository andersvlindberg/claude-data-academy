# Lab 61: Business case for a data project

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Business / MarTech · Data analyst | L2 | 2 h | Slides, Sheets | Free |

**Goal:** Get a data initiative approved: value, cost, risks and stakeholders.

## Run it with Claude Code
```bash
mkdir lab-61-data-project-business-case && cd lab-61-data-project-business-case
git init
claude
```
Type `LAB 61`. This is a brief lab: the coach turns the milestones below into steps that fit your level and stack, and you write the code.

## Milestones
1. Define the problem and who has it
2. Quantify value with conservative assumptions
3. Map stakeholders and their concerns
4. Write a one-page proposal

## Done when
- [ ] Assumptions explicit
- [ ] Clear ask

## Portfolio
A one-page proposal.

> Safety: use fake or public data, keep secrets in `.env` (in `.gitignore`), and Claude asks before anything destructive.
