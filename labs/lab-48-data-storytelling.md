# Lab 48: Data storytelling: a 5-slide recommendation

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Data analyst · Business / MarTech | L2 | 2 h | Slides | Free |

**Goal:** Turn an analysis into a recommendation a manager acts on.

## Run it with Claude Code
```bash
mkdir lab-48-data-storytelling && cd lab-48-data-storytelling
git init
claude
```
Type `LAB 48`. This is a brief lab: the coach turns the milestones below into steps that fit your level and stack, and you write the code.

## Milestones
1. Write the one-sentence answer first
2. Pick the 3 charts that prove it, with action titles
3. Add the ask and the risk
4. Rehearse in 3 minutes

## Done when
- [ ] A stranger states the takeaway after 1 minute
- [ ] Every chart has an action title

## Portfolio
A 5-slide deck.

> Safety: use fake or public data, keep secrets in `.env` (in `.gitignore`), and Claude asks before anything destructive.
