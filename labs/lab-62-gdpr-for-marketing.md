# Lab 62: GDPR for a marketing campaign

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Business / MarTech | L2 | 2 h | Docs | Free |

**Goal:** Check a campaign's lawful basis, consent and data minimisation before launch.

## Run it with Claude Code
```bash
mkdir lab-62-gdpr-for-marketing && cd lab-62-gdpr-for-marketing
git init
claude
```
Type `LAB 62`. This is a brief lab: the coach turns the milestones below into steps that fit your level and stack, and you write the code.

## Milestones
1. Describe purpose, data and recipients
2. Choose the lawful basis per purpose
3. Check consent text, retention and opt-out
4. Decide whether a DPIA is needed

## Done when
- [ ] Each purpose has a lawful basis
- [ ] Retention defined

## Portfolio
A campaign privacy checklist.

> Safety: use fake or public data, keep secrets in `.env` (in `.gitignore`), and Claude asks before anything destructive.
