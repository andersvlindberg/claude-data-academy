# Lab 51: DA capstone: quarterly business review for Nordvik

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Data analyst | L3–L4 | 8–10 h | SQL, Looker Studio or Tableau, Slides | Free |

**Goal:** Deliver a quarterly review: performance, customers, experiments and recommendations.

## How this lab works
1. **Hub:** open this step in your study hub and take the lecture (*Lecture*), or skip it if you know the theory.
2. **Claude Code:** the lecture ends with a practice project. Claude sets it up for you (a fictional scenario and generated data) and you build it in a real tool.
3. **GitHub:** commit as you go and merge it into your fork. Then tick it off in the hub.

```bash
cd claude-data-academy        # your fork
git checkout -b lab-51
mkdir -p my-work/lab-51-da-capstone && cd my-work/lab-51-da-capstone
claude
```
Type `LAB 51`. This is a brief lab: the coach turns the milestones below into steps for your level, and you write the code.

## Milestones
1. KPI dashboard with metric tree
2. Customer segments and retention
3. One experiment or attribution deep dive
4. A 10-minute presentation with recommendations

## Done when
- [ ] Every number reconciles
- [ ] Recommendations are specific and measurable

## Save it to your portfolio
```bash
git add .
git commit -m "lab 51: <what you built>"
git push -u origin lab-51
```
Open a pull request in your fork, read your own diff like a reviewer, merge it, and mark the lab *Done* in your hub. Add a short `README.md` in the lab folder: what you built, how to run it, what you learned.
