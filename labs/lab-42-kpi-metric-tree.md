# Lab 42: KPI design: a metric tree for e-commerce

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Data analyst · Business / MarTech | L2 | 2 h | Sheets or whiteboard | Free |

**Goal:** Break revenue down into drivers so every team knows which number it moves.

## Run it with Claude Code

Type `LAB 42`. This is a brief lab: the coach turns the milestones below into steps that fit your level and stack, and you write the code.

## Milestones
1. Start from revenue = sessions × conversion × AOV
2. Add drivers per team (marketing, product, CRM)
3. Define each metric precisely (formula, grain, source)
4. Pick 5 KPIs and their targets
