# Lab 60: CDP evaluation: composable vs packaged

| Role | Level | Time | Tools | Cost |
|---|---|---|---|---|
| Business / MarTech · Analytics engineer | L2–L3 | 3 h | Slides, Sheets | Free |

**Goal:** Decide between a packaged CDP and a warehouse-first composable setup.

## How this lab works
1. **Hub:** open this step in your study hub and take the lecture (*Lecture*), or skip it if you know the theory.
2. **Claude Code:** the lecture ends with a practice project. Claude sets it up for you (a fictional scenario and generated data) and you build it in a real tool.
3. **GitHub:** commit as you go and merge it into your fork. Then tick it off in the hub.

```bash
cd claude-data-academy        # your fork
git checkout -b lab-60
mkdir -p my-work/lab-60-cdp-business-case && cd my-work/lab-60-cdp-business-case
claude
```
Type `LAB 60`. This is a brief lab: the coach turns the milestones below into steps for your level, and you write the code.

## Milestones
1. List use cases and required data
2. Compare options on cost, speed, control and privacy
3. Estimate 3-year cost
4. Recommend with risks

## Done when
- [ ] Use cases drive the choice
- [ ] Costs stated with assumptions

## Save it to your portfolio
```bash
git add .
git commit -m "lab 60: <what you built>"
git push -u origin lab-60
```
Open a pull request in your fork, read your own diff like a reviewer, merge it, and mark the lab *Done* in your hub. Add a short `README.md` in the lab folder: what you built, how to run it, what you learned.
