# Slide system

## Layout catalogue (16:9)
| Layout | Use |
|---|---|
| Title (dark, large statement + subtitle) | Opening |
| Agenda (numbered cards) | Orientation |
| Section divider (dark, huge number) | Rhythm between parts |
| Big number + context | One key metric |
| Chart + takeaway column | Data insight |
| Two-column compare | Before/after, option A/B |
| 2×2 or 2×4 cards with icons | Lists of concepts |
| Process/timeline (numbered steps on one axis) | Flows, methods |
| Quote / statement | Emphasis |
| Recommendation + next steps (dark) | Close |

Keep the title at the same position, size and style on every content slide.

Check contrast: body text at least 4.5:1 against its background.

## Type scale
Title 36–44 · section header 20–24 · body 14–18 · caption 10–12. Safe fonts for PowerPoint that render consistently: Calibri, Arial, Cambria, Century Schoolbook. Pair a serif heading with a sans body for contrast, or use one family with weight contrast.

## Techniques by goal
| Goal | Technique |
|---|---|
| Focus | Big-number callout (60–96 pt); grey everything except the point |
| Hierarchy | Small uppercase kicker label above the title in the accent colour; tonal steps (dark/mid/light text) |
| Rhythm | Dark section dividers; dark title and closing, light content ("sandwich") |
| Depth without clutter | One soft shadow style on cards only; pale accent tint behind call-out boxes |
| Hand-crafted feel | Topic-specific palette; one repeated motif; purposeful asymmetry; context boxes that separate your own explanation from source material |
| Data clarity | Direct labels; highlight one series; annotate the moment that matters |

## Avoid
- Accent lines under titles; decorative bars along slide or card edges.
- Everything centred; walls of bullets; text-only slides.
- Purple-blue gradients as default personality; emoji as icons in professional decks.
- Equal weight for all colours; card grids with no hierarchy.

## PowerPoint production notes
- Build from layouts/placeholders so the deck is editable and consistent.
- Speaker notes for detail, not text boxes on the slide.
- Export to PDF as a backup for presenting without a live demo.
- Before delivering, render every slide to an image and inspect: overflow, overlaps, alignment, contrast, broken words.
