# Exercises: Presentation design

## Set A (practitioner)

1. Rewrite five topic titles as action titles ("Revenue" → "...").
2. Restructure a ten-slide deck into the pyramid: answer, three arguments, evidence.
3. Take one cluttered chart and remove clutter step by step; highlight the one point.
4. Write an SCQA opening for an analysis of falling repeat purchases.

## Set B (independent)

1. Build a six-slide deck for the capstone's first milestone using a defined palette, type scale and motif; render it and run the review checklist.
2. Present the same finding three ways: executive (3 slides), marketing team (6 slides), data team (technical appendix).
3. Record a 5-minute rehearsal, then improve pacing and the first and last sentences.
4. Turn a tracking investigation into a five-part evidence-chain presentation.

## Quiz bank

1. What is an action title?
2. What does SCQA stand for?
3. How many minutes per content slide is a good rule?
4. Why grey out context data?
5. Name three anti-patterns that make slides look generated.

## Interview questions

1. "Present a project you are proud of in three minutes."
2. "How would you explain a complex data model to a marketing director?"
3. "Tell me about a time your analysis changed someone's mind."
