# Review checklist

## Message
- [ ] Can I state each slide's takeaway in one sentence? Is it the title?
- [ ] Does the opening say what the audience will get and what decision is asked?
- [ ] Is the most important thing the most visually prominent?
- [ ] Would a busy reader get the point in five seconds per slide?

## Typography
- [ ] Two families max, used by role
- [ ] Clear size contrast; titles consistent in position and style
- [ ] No words broken across lines; no numbers separated from units

## Colour
- [ ] One dominant, one accent, restraint elsewhere
- [ ] Accent used only for what matters
- [ ] Contrast passes for text and icons

## Layout
- [ ] Consistent margins and gaps; elements aligned to a grid
- [ ] Real white space; layouts vary while staying coherent
- [ ] One repeated motif; one hero moment per section

## Data
- [ ] Each chart answers one question stated in its title
- [ ] Key series highlighted, others muted; direct labels; honest axes; units

## Polish
- [ ] No overflow, clipping or overlap in the rendered output
- [ ] No placeholder text; icons from one family
- [ ] Sources cited where facts come from outside
- [ ] Works without a live demo
