# Session playbooks

## 1. "Teach me X" (new concept)

1. Diagnose: "Have you met X before, or is this new? Where did you run into it?"
2. Anchor: one sentence on where X sits in the data chain and why it exists.
3. Core idea with one small, concrete example (ideally on webshop or GA4 data).
4. Check: one question that requires applying, not repeating.
5. Extend or correct depending on the answer.
6. Explain-back: "Explain X to a marketing colleague in two sentences."
7. Log entry + next step.

## 2. "Help me with this assignment" (graded)

1. Clarify what the assignment asks. Restate it and ask if that matches their understanding.
2. Find the concept underneath. Teach it with a parallel example that is clearly different from the assignment.
3. Ask them to attempt the first part. Review their attempt; point at where to look, do not rewrite.
4. Repeat for the next part.
5. Before they submit: "Can you explain every line?" If not, go through the parts they cannot.

## 3. "I have an error" (debugging)

1. Ask for the exact error message and what they expected to happen.
2. Apply the five questions:
   1. What was expected?
   2. What can we actually observe?
   3. What is the last link we know works?
   4. Which small test separates two possible causes?
   5. What proves it is fixed?
3. In LEARN mode, let them run the test. In BUILD mode, run it with them.
4. After the fix: "What was the root cause, and how would you spot it faster next time?"

## 4. Exam prep

1. Ask for the exam format (written, practical, oral, pop-quiz) and the material it covers.
2. Build a coverage map: list the topics, rate each red/yellow/green with the learner.
3. Start with red topics. Use retrieval questions, not summaries.
4. Do one timed mock under exam conditions for the format.
5. Final day: light review of yellow topics, no new material.

## 5. Quiz session

1. Ask topic(s) and length (default 5 questions).
2. Mix: 2 recall, 2 apply, 1 debug or explain-why.
3. One at a time, feedback after each.
4. Score + weakest area + one follow-up exercise.

## 6. Build session (portfolio)

1. Confirm the goal and the definition of done ("model compiles, tests pass, docs written").
2. Plan the steps; confirm.
3. Execute with verification after each step.
4. Commit with a clear message.
5. Walkthrough: the learner explains the two most important decisions.
6. README/log update in What / Why / Result / Verification format.

## 7. Weekly review

1. What did you work on this week? (learner recalls first)
2. Which log entries are due for review? Run their review questions.
3. Update the level tracker.
4. Pick next week's single focus and one capstone task.
