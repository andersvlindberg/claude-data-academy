# Routing: which skill answers what

| Question is about... | Load |
|---|---|
| What data is, the lifecycle, data roles, observation vs interpretation | `ae-foundations` |
| Writing or fixing SQL | `ae-sql` |
| Tables, keys, grain, facts and dimensions, normalisation, SCD | `ae-modeling` |
| Pipelines, ELT, ingestion, orchestration, Airflow, Docker, streaming | `ae-data-engineering` |
| dbt anything | `ae-dbt` |
| BigQuery, Snowflake, DuckDB specifics, cost, roles, performance | `ae-warehouses` |
| Clicks, HTTP, DevTools, cookies, identity, data layer, GTM, consent, GA4 | `ae-web-tracking` |
| MarTech stack, CDP, CRM, marketing automation, KPI formulas, RACI | `ae-martech` |
| Customer journeys, touchpoints, business processes, business cases, stakeholders | `ae-business-journeys` |
| EDA, funnels, cohorts, segmentation, A/B tests, root cause | `ae-analytics` |
| Metric definitions, semantic layer, dashboards, Looker Studio, Power BI | `ae-bi-metrics` |
| GDPR, legal basis, PII, consent law, data quality, data contracts, ownership | `ae-governance-gdpr` |
| REST APIs, JSON, auth, webhooks, pagination, integrations, reverse ETL | `ae-apis` |
| Python, classes, OOP, testing, pandas | `ae-python` |
| Machine learning, churn, CLV models, LLMs, RAG, agents | `ae-ai-ml` |
| Git, GitHub, branches, PRs, CI/CD | `ae-git-devops` |
| Project management, agile, requirements, troubleshooting method | `ae-project-method` |
| Slides, reports, data storytelling, presenting | `ae-presentation-design` |
| MCP, Claude Code, connecting Claude to tools | `ae-mcp-tooling` |
| Portfolio, CV, internship, interviews | `ae-career` |
| CRM, lifecycle, leads, tickets, marketing automation flows, email/SMS, holdouts | `ae-crm-automation` |
| CDP, data sources and flows, identity resolution, customer 360, segments, activation, adtech | `ae-customer-data-platforms` |
| GA4 reporting, measurement plans, CRO, UTMs, attribution, marketing analytics | `ae-digital-analytics` |
| Statistics, confidence intervals, hypothesis tests, experiment design, regression, surveys | `ae-statistics` |
| Organisation, business idea, vision, Business Model Canvas, goals, SMART, KPIs, data maturity | `ae-business-strategy` |
| ERP, OMS, WMS, PIM, CMS, business processes, master data, migration | `ae-systems-processes` |

Many questions span two skills (for example "model GA4 sessions in dbt" = `ae-web-tracking` + `ae-dbt`). Load both.
| Visual design of decks, dashboards, reports, web pages, UI | `ae-design` (+ `ae-presentation-design`) |
| Excel, Google Sheets, pivots, XLOOKUP, Power Query | `ae-spreadsheets` |
