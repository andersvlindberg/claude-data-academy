# Learning science the coach applies

## The five techniques that matter most

| Technique | What it is | How the coach uses it |
|---|---|---|
| Retrieval practice | Pulling information out of memory strengthens it more than re-reading | Ask before telling. Every review starts with "what do you remember about...?" |
| Spacing | Reviewing over increasing intervals beats cramming | Log a review date: +1 day, +1 week, +1 month, +3 months |
| Interleaving | Mixing problem types forces you to choose the right method | Past L1, quizzes mix topics (a join question, then a GDPR question, then a dbt test question) |
| Worked examples | Beginners learn procedures faster from studied examples than from solving blind | Show a parallel example with narrated reasoning, then fade support step by step |
| Elaboration | Explaining why and connecting to what you know | Ask "why does this work?" and "where in the chain does this happen?" |

## Desirable difficulty

Learning that feels a bit hard sticks better. Struggle is productive when the learner has the pieces and is assembling them. It is unproductive when a prerequisite is missing. The coach's job is to tell the two apart and give a foothold in the second case.

## Fading scaffolds

1. Full worked example with narration.
2. Example with the last step left for the learner.
3. Example with the middle steps left.
4. Only the problem, with a hint available.
5. Only the problem.

Move down one rung when the learner succeeds twice in a row; move up one when they fail twice.

## Misconceptions

Each topic skill lists common misconceptions. When a learner shows one:
1. Make the misconception explicit ("It sounds like you expect a LEFT JOIN to remove rows").
2. Give a small counterexample they can run or reason through.
3. Let them restate the correct model.

Correcting by contradiction alone ("no, that's wrong") rarely sticks. Counterexamples do.

## Cognitive load

- One new idea per turn.
- Use the learner's own data and examples (their webshop, their tracking lab) where possible; familiar context frees capacity for the new concept.
- Prefer a diagram over a paragraph when the concept is structural.

## Spaced review schedule

| Review | When | Format |
|---|---|---|
| 1 | Next day | 3 recall questions |
| 2 | One week | 5 mixed questions incl. one apply |
| 3 | One month | Mini task (write a query, explain a model) |
| 4 | Three months | Interview-style question with follow-ups |
