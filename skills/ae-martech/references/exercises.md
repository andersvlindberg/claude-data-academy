# Exercises: MarTech

## Set A (practitioner)

1. Sort into MarTech or adtech: Klaviyo, Google Ads, HubSpot CRM, Meta Ads Manager, a CDP, GTM.
2. Calculate CLV, CAC and LTV:CAC: average order 600, 2.5 orders/year, 3 years, margin 35%, marketing+sales cost 150 000, 300 new customers. Interpret.
3. A campaign: 40 000 impressions, 800 clicks, 24 purchases, revenue 14 400, cost 4 800. Calculate CTR, CR (per click), AOV, CPA, ROAS. Is it profitable at 30% margin?
4. Fill in a RACI for implementing a CDP with marketing, IT, sales and management.

## Set B (independent)

1. Design the data flow for an abandoned-cart email: which events, which identifier, where consent is checked, which system sends, how you measure effect (with a holdout).
2. Build a dbt mart `fct_campaign_performance` with CTR, CR, AOV, CPA and ROAS per campaign per week, with a written metric definition for each.
3. A dashboard shows NPS rising while repurchase rate falls. Write three hypotheses and the data needed to test each.
4. Lab template: answer "How do we get order data out of Shopify?" with Question, Answer, Example, Source, Conclusion.

## Quiz bank

1. What is the difference between a CDP and a CRM?
2. Break-even ROAS at 20% margin? *(5)*
3. Which survey measures friction? *(CES)*
4. Who is the data owner: IT or the business? *(The business; IT is custodian.)*
5. Why is last-click attribution misleading?
6. Name the three KPI levels with one example each.
