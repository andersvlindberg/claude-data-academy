# Exercises: Analytics

## Set A (practitioner)

1. Run the EDA checklist on the orders table and list three surprises.
2. Build a session funnel by device and identify the step with the biggest drop on mobile.
3. Build a monthly cohort retention table and describe one pattern.
4. Score customers with RFM and count customers per segment.

## Set B (independent)

1. Revenue dropped 18% last week. Run a full root cause analysis with the template on the practice data (the coach can plant a cause).
2. Design an A/B test for a new checkout button: hypothesis, metrics, MDE, sample size, duration, SRM check.
3. Analyse given A/B results with a confidence interval and write the recommendation for a non-technical manager.
4. Construct a small dataset that shows Simpson's paradox and explain it.

## Quiz bank

1. What does SRM indicate?
2. Why is peeking a problem?
3. What does a p-value of 0.03 mean, and not mean?
4. In RFM, why is the recency score reversed?
5. Mix effect versus rate effect: give an example.

## Interview questions

1. "Conversion dropped yesterday. Walk me through your first hour."
2. "How do you decide if an A/B test result is trustworthy?"
3. "Tell me about an analysis that changed a decision."
