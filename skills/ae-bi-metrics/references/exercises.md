# Exercises: Metrics and BI

## Set A (practitioner)

1. Write full definitions for revenue, AOV and conversion rate for the practice webshop.
2. Connect Looker Studio (or Power BI) to a mart and build a KPI row with comparison to the previous period.
3. Pick the right chart: revenue per month for two years; revenue by channel this month; relation between discount and AOV; exact order list.
4. Show with numbers why averaging daily conversion rates gives the wrong monthly rate.

## Set B (independent)

1. Implement conversion rate and AOV in a semantic layer or as a tested metric mart, and query them by channel and month.
2. Design a dashboard for the Head of E-commerce's Monday meeting: purpose, layout sketch, metrics, comparisons, freshness note.
3. Two teams report different "active customers". Write a resolution: definitions, decision, change communication.
4. In Power BI, build a star model with `fct_orders` and three dimensions and DAX measures for revenue, AOV and YoY.

## Quiz bank

1. What must a metric definition contain? (name five elements)
2. Pros and cons of a semantic layer?
3. Import versus DirectQuery?
4. Where should core KPI logic live, and why?
5. Which chart for a trend over time?

## Interview questions

1. "How do you make sure revenue means the same thing everywhere?"
2. "Design a dashboard for a CMO. What is on it and why?"
3. "What is a semantic layer and when is it worth it?"
