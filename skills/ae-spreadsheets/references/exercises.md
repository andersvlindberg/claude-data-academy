# Exercises: Spreadsheets

## Set A (practitioner)
1. With an orders table, compute revenue per customer with SUMIFS and per month with a pivot table.
2. Look up product category for each order line with XLOOKUP; handle missing products with IFERROR.
3. Clean a messy customer list: trim, lowercase emails, remove duplicates.

## Set B (independent)
1. Build a small CLV model with an inputs sheet, a calculation sheet and an output sheet with a chart; document assumptions.
2. Use Power Query to combine twelve monthly CSV files into one refreshable table.
3. Take a spreadsheet report used weekly and write a migration plan to a dbt model plus dashboard, including how you will reconcile old and new numbers.

## Quiz bank
1. Why prefer XLOOKUP over VLOOKUP?
2. What does Power Query do that formulas don't?
3. Name three signs a spreadsheet should become a dbt model.
