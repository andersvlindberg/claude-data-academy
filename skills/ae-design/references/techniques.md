# Techniques by goal

| Goal | Techniques |
|---|---|
| Focus | Big-number callout (60–96 pt); isolate the key element with space; grey context, accent for the point; scale jump of 2–3× |
| Hierarchy | Small uppercase tracked kicker above titles; weight contrast; tonal steps (dark, mid, light text); large accent numerals for sequence |
| Rhythm | Full-bleed section dividers; dark opening and closing with light content; alternating layouts; one consistent card system |
| Depth without clutter | One soft shadow style on cards only; pale accent tint behind callouts; a large shape bleeding off the edge; quiet outlined rings |
| Hand-crafted feel | Named, topic-specific palette; one repeated motif; purposeful asymmetry; editorial pull quotes; context boxes separating your explanation from sources |
| Data clarity | Direct labels; highlight one series; small multiples; sparklines in tables; KPI tile = label, value, delta, tiny trend; annotate the moment that matters |
| Guide the eye | Z-pattern for title and landing pages; F-pattern for text pages; icon-in-circle rows; numbered flows on one axis |

## Medium notes
- **Slides:** one message per slide, action titles, vary layouts, titles in the same position.
- **Dashboards:** KPI row, then trends, then breakdowns, then detail; filters on top; "as of" timestamp.
- **Web pages:** fluid grid, spacing scale, two fonts max, light and dark tokens, hover and focus states.
- **Reports and PDFs:** cover, summary, running header and footer, page numbers, captions, print margins.
- **Spreadsheets:** frozen header, consistent number formats, inputs visibly different from formulas, muted gridlines, one accent for totals or flags.

## Anti-patterns (they read as generated)
Accent lines under titles · coloured bars along slide or card edges · everything centred · purple-to-blue gradients as default personality · emoji as icons in professional work · all colours equal weight · grids of identical cards with no hierarchy · shadows, gradients and rounded corners stacked on one element · text-only slides · stock phrases like "Unlock" and "Seamless".
