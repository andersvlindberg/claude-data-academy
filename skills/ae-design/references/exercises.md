# Exercises: Design

## Set A (practitioner)
1. Take a default chart and apply five clutter-removal steps; highlight one series.
2. Define a palette (dominant, primary, accent) and type scale for a data report about customer churn.
3. Rewrite a cluttered slide with one message, an action title and a single visual.
4. Add GSAP entrance animations and Lenis smooth scrolling to a static HTML report page; make it work with reduced motion and with JavaScript off.

## Set B (independent)
1. Redesign a dashboard with the full process and checklist; show before and after.
2. Build a small design system (tokens for colour, type, spacing, radius) for your capstone and apply it to a deck and a dashboard.
3. Audit a web page for accessibility (contrast, focus, alt text, labels) and fix three issues.
4. Build a KPI landing page for your capstone with a count-up hero number, bars that grow on scroll and one React Bits text animation. Write the motion rules for your design system.

## Quiz bank
1. Name four reference directions and what each is good for.
2. What is the data-ink ratio?
3. Minimum contrast ratio for body text?
4. Name five anti-patterns that make design look generated.
5. Why animate only transform and opacity?
6. What three lines connect Lenis to GSAP ScrollTrigger, and why multiply by 1000?
7. How should a page behave when prefers-reduced-motion is set?
