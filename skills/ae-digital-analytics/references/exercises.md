# Exercises: Digital analytics

## Set A (practitioner)

1. Write a measurement plan for a gym's website (memberships online).
2. Write a tracking plan with six events for the same site.
3. In the GA4 demo account, build a funnel exploration for the purchase journey and describe the biggest drop.
4. Create a UTM naming convention and tag five campaign links correctly.

## Set B (independent)

1. Run a CRO research sprint on a public landing page: heuristic review, three hypotheses in the template, prioritised with ICE.
2. Build channel performance in the warehouse from GA4 export + ad cost data with CPA and ROAS per channel per week.
3. Compare last-click and data-driven attribution for the GA4 sample data and explain the differences to a CMO.
4. Design a geo holdout test to measure incrementality of paid social.

## Quiz bank

1. What is a key event in GA4?
2. Why should internal links never carry UTMs?
3. Reports versus explorations?
4. What does PIE stand for?
5. When do you use MMM instead of attribution?
6. Name three privacy-friendly collection practices.

## Google Analytics certification prep
The certification is free in Google Skillshop. Check the current exam guide; topics have typically covered: setting up GA4 (properties, data streams, tags), collecting and customising data (events, key events, custom dimensions), reports and explorations, audiences and remarketing, attribution, and linking to other Google products. Work through Skillshop's own course, practise in the GA4 demo account, and quiz yourself with the coach per topic.
