# Exercises: Business and journeys

## Set A (practitioner)

1. Map the journey of signing up for a gym membership online. Fill in all rows of the template, including data created.
2. Build a metric tree for "revenue" of a webshop down to three levels.
3. For three pain points from your map, score impact, reach and effort and pick the first to fix.
4. Translate this request into a data requirement: "We want to know if our newsletter works."

## Set B (independent)

1. Draw a service blueprint for a product return: customer actions, frontstage, backstage, systems and data created at each step.
2. Write a business case for introducing a CDP at a mid-size retailer, with a sensitivity analysis and a measurement plan.
3. A manager asks for "a dashboard with everything". Run a short requirements conversation (role-play with the coach) and produce: decisions supported, questions, metrics with definitions.
4. Combine a journey map with real webshop data: compute the conversion rate between each consecutive stage and identify the biggest drop.

## Quiz bank
