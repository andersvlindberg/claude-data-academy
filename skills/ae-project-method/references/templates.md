## User story with acceptance criteria
```
As a marketing manager,
I want revenue by channel per week,
so that I can reallocate budget on Mondays.

Acceptance criteria:
- Given completed orders, when I open the dashboard on Monday 08:00, then last week's revenue by channel is shown.
- Given the metric definition "revenue", then the dashboard total equals fct_orders for the same week (±0.5%).
- Given a channel with no sessions, then it shows 0, not blank.
```
