# Exercises: Project method

## Set A (practitioner)

1. Write three user stories with acceptance criteria for a webshop sales dashboard.
2. Prioritise ten backlog items with MoSCoW and justify the musts.
3. Create a RACI for a five-person group project with a presentation.
4. Map a real troubleshooting case (any bug) onto the five questions.

## Set B (independent)

1. Write a project charter and two-sprint plan for building the capstone's first dbt layer.
2. Run a retrospective on your last group project and turn it into three concrete actions.
3. Build a risk register for the capstone with at least six risks and mitigations.
4. Lead (or simulate with the coach) a 15-minute sprint planning: goal, backlog selection, task breakdown, owners.

## Quiz bank

1. Name the three Scrum roles and five events.
2. What does a WIP limit do?
3. What is the difference between Responsible and Accountable?
4. What makes a good acceptance criterion?
5. What are the five troubleshooting questions?

## Interview questions

1. "How do you handle a stakeholder who keeps changing requirements?"
2. "Tell me about a group project where something went wrong. What did you do?"
3. "How do you decide when a data model is done?"
