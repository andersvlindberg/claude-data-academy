# Exercises: Career

## Set A (practitioner)

1. Write your moat in three sentences: identity, bridge, evidence.
2. Rewrite three CV bullets from a non-data job as action + tool + result.
3. Draft the capstone README skeleton from the template.
4. List ten target companies with a real data team, and for each the stack you can see in job ads.

## Set B (independent)

1. Run a 30-minute mock interview with the coach (SQL, modeling case, one behavioural question) and act on the feedback.
2. Write and rehearse your 60-second pitch; record it and cut it to under 60 seconds.
3. Prepare five STAR stories from projects and previous jobs, each with a number in the result.
4. Go to one event or hackathon; afterwards write who you met, what you learned and one follow-up.

## Quiz bank

1. What are the parts of STAR?
2. Name three things a strong data portfolio README contains.
3. Why does one deep project beat many shallow ones?
4. What questions should you ask an interviewer about their data team?
