## Capstone checklist
- [ ] Public repo, clear name, description and topics
- [ ] README as above with a diagram
- [ ] Commits spread over time with clear messages
- [ ] dbt project with tests, docs, and a lineage screenshot
- [ ] CI badge passing
- [ ] Dashboard screenshot or link
- [ ] No secrets, no personal data, sample or synthetic data only
- [ ] A short learning log showing progression

## CV for data roles
- Headline: target role + strongest evidence ("Customer data developer student, analytics engineering: dbt, BigQuery, Snowflake").
- Experience bullets: action + tool + measurable result. Translate non-data roles into transferable skills (customer understanding, process improvement, payments/fraud patterns, reporting).
- Projects section with links.
- Skills grouped: languages, tools, methods.
- One to two pages; no photo needed in many markets; tailor per application.

## LinkedIn
Headline with both the education title and the market title. About section in first person, short sentences, concrete. Featured: the capstone repo and one presentation.
