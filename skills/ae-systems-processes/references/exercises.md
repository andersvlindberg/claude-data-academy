# Exercises: Systems and processes

## Set A (practitioner)

1. Match ten business needs to the right system type (e.g. "product descriptions in three languages" → PIM).
2. Draw order to cash for a webshop with the records created at each step.
3. Name the source of truth for customer, product, price, stock and invoice in an omnichannel retailer, with reasons.

## Set B (independent)

1. Map the return process for a furniture chain with swimlanes per system and list where data gets lost.
2. Write a field mapping and reconciliation plan for migrating customers from an old CRM to a new one.
3. Design how order status should be modeled in the warehouse when it changes over time (snapshot or event table) and justify it.

## Quiz bank

1. ERP versus CRM?
2. What is master data?
3. What does a headless CMS do?
4. Why can revenue differ between commerce and ERP?
5. Name the seven migration steps.

## Interview questions

1. "Walk me through order to cash and where you'd get data for each step."
2. "How would you approach migrating to a new e-commerce platform without losing history?"
