# Exercises: AI and ML

## Set A (practitioner)

1. Classify each problem: predict delivery delay in days; group customers by behaviour; predict whether an email is opened; suggest products.
2. Explain leakage with your own example from e-commerce.
3. A churn model has 94% accuracy and 6% of customers churn. What do you check?
4. Write a prompt that makes an LLM answer only from provided metric definitions.

## Set B (independent)

1. Build a point-in-time churn dataset in dbt, train a logistic regression, compare to a recency rule, and report precision/recall at a chosen threshold.
2. Run k-means on RFM features, choose k with reasoning, and describe each segment in business terms with a suggested action.
3. Build a small company-brain prototype: index your dbt docs and metric definitions, answer questions with sources, and evaluate it on 15 golden questions.
4. Write a one-page risk assessment for using a churn score to give discounts: GDPR, bias, Art. 22, monitoring.

## Quiz bank

1. Precision versus recall: which matters more for a costly retention offer?
2. What is RAG and what problem does it solve?
3. Why is text-to-SQL more reliable on a semantic layer?
4. What is a golden set?
5. What does Art. 22 GDPR restrict?

## Interview questions

1. "How would you build a churn model from our warehouse, and how would you know it adds value?"
2. "How can an LLM agent help an analytics team, and what are the risks?"
3. "What makes data AI-ready?"
