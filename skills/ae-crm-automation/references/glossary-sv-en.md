# Swedish–English glossary: CRM, MarTech and customer data

| Svenska | English | Short meaning |
|---|---|---|
| Kunddata | Customer data | Information about the customer and the relationship |
| Förstapartsdata | First-party data | Data the company collects directly from its customers |
| Andrapartsdata / tredjepartsdata | Second-/third-party data | Partner's first-party data / bought or aggregated data |
| Kundprofil, 360-vy | Customer profile, customer 360, single customer view | One connected view of a customer |
| Identitetsmatchning | Identity resolution | Linking identifiers to one person |
| Deterministisk / probabilistisk matchning | Deterministic / probabilistic matching | Certain (login, email) / likely (device, IP, behaviour) |
| Dubbletter, deduplicering | Duplicates, deduplication | Same customer multiple times; merging them |
| Kundresa | Customer journey | The customer's experience over time |
| Kontaktpunkt | Touchpoint | Where customer and company meet |
| Sanningens ögonblick | Moment of truth | Decisive moment for the customer's judgement |
| Smärtpunkt | Pain point | Friction or frustration |
| Kundlivscykel | Customer lifecycle | Stages from prospect to loyal/lapsed |
| Kundvärde över tid | Customer lifetime value (CLV/LTV) | Value of the whole relationship |
| Kundanskaffningskostnad | Customer acquisition cost (CAC) | Cost to win a new customer |
| Kundbortfall | Churn | Share of customers who leave |
| Kundlojalitet, återköpsgrad | Loyalty, repurchase rate | Customers who come back |
| Konverteringsgrad | Conversion rate | Share who complete a goal |
| Snittordervärde | Average order value (AOV) | Revenue per order |
| Nyckeltal | KPI | Key performance indicator |
| Ledande / släpande nyckeltal | Leading / lagging indicator | Predicts / reports outcomes |
| Utskick, nyhetsbrev | Send-out, newsletter | Mass communication |
| Flöde, arbetsflöde | Flow, workflow | Automated sequence of steps |
| Utlösare | Trigger | Event that starts a flow |
| Spärrlista, undantag | Suppression list | Who must not receive a message |
| Samtycke, avregistrering | Consent, unsubscribe | Permission and its withdrawal |
| Ärende | Ticket, case | Service request |
| Kundtjänst | Customer service | Support function |
| Svarstidsavtal | SLA (service level agreement) | Agreed response/resolution time |
| Lösning vid första kontakt | First contact resolution (FCR) | Solved without follow-up |
| Säljtratt, pipeline | Sales funnel, pipeline | Opportunities by stage |
| Affärsmöjlighet | Opportunity / deal | Potential sale |
| Leadpoäng | Lead score | Fit + engagement score |
| Ägda / köpta / förtjänade kanaler | Owned / paid / earned media | Own channels / ads / reviews and word of mouth |
| Annonsteknik | Adtech | Advertising technology |
| Realtidsbudgivning | Real-time bidding (RTB) | Automated ad auction |
| Datalager | Data warehouse | Analysis-ready central store |
| Datasjö | Data lake | Cheap raw storage |
| Dataägare / dataförvaltare / dataförvarare | Data owner / steward / custodian | Purpose / quality / operations |
| Silo | Silo | Isolated data or department |
| Integrationer | Integrations | Connections between systems |
| Gränssnitt för program | API | How systems talk |
| Webhook | Webhook | System pushes data when something happens |
| Nyttolast | Payload | The data that is sent |
| Anropsgräns | Rate limit | Max calls allowed |
| Varumärkeslöfte | Brand promise | The expectation the brand sets |
| Kundupplevelse | Customer experience (CX) | The delivery of the promise |
| Affärsnytta | Business value | Measurable benefit |
